# Paper Portfolio Guidance

继承 `../AGENTS.md`。每个 `P-YYYY-NNN-*` 目录代表一篇独立论文。

- `PAPER.yaml` 是论文状态的权威来源；`INDEX.yaml` 与 `STATUS.md` 是可重建派生文件。
- `00_source/`、`04_journal/*/official/` 和投稿回执均为不可变输入，不得覆盖、删除或原地编辑。
- 中文到英文的修改必须保留内容单元 ID；语言修改不得静默改变科学结论、数值、单位或引用。
- 期刊要求必须来自官方页面并记录核验日期；未知要求标记为 unresolved，禁止猜测。
- DOCX 交付必须完成结构审计和全页渲染检查；视觉检查不能替代字段、批注、修订和 OOXML 关系检查。
- 投稿、换刊、改变核心结论、删除实验结果和提交返修必须经过对应人工关卡。
- `.paperflow/jobs/` 保存本地 Agent 作业、副本、候选输出和应用记录；它不是论文状态事实源。Agent 候选只有在用户接受并通过受控应用检查后才能进入单篇论文目录。
